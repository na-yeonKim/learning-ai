# Learning AI

Independent deep-learning projects completed while studying Computer Engineering at Yeungnam University. These notebooks explore computer vision, human pose estimation, Korean-language modeling, and text processing.

## Projects

| Notebook | Project |
|---|---|
| [ResNet.ipynb](ResNet.ipynb) | Compare ResNet-34/50 and plain CNN variants on Oxford-IIIT Pet; examine overfitting and classification performance. |
| [Augmentation.ipynb](Augmentation.ipynb) | Compare image augmentation strategies, including MixUp and CutMix, for pet-breed classification. |
| [CAM_GradCAM.ipynb](CAM_GradCAM.ipynb) | Visualize image regions contributing to ResNet predictions with CAM and Grad-CAM. |
| [pose_estimation.ipynb](pose_estimation.ipynb) | Estimate 16 human keypoints from MPII images using heatmap-based pose-estimation models. |
| [miniBERT.ipynb](miniBERT.ipynb) | Prepare Korean MLM/NSP pretraining examples and train a compact BERT-style model. |
| [chatbot.ipynb](chatbot.ipynb) | Implement a Korean dialogue-generation model with a Transformer encoder-decoder. |
| [Transformer2GPT.ipynb](Transformer2GPT.ipynb) | Convert the dialogue model to a GPT-style decoder-only next-token prediction setup. |
| [Summarization.ipynb](Summarization.ipynb) | Compare LSTM+Attention abstractive news summarization with Summa extractive summarization. |
| [vocabulary.ipynb](vocabulary.ipynb) | Compare MeCab and SentencePiece tokenization settings in Korean sentiment classification. |

## Notes

- This repository contains learning and implementation projects, not original research results.
- Dataset files and model checkpoints are not included. The notebooks describe or download the datasets used.
